# eigur.in

Welcome to eigur.in - A premium digital experience featuring games, news, and interactive content.

## Features

- **Tic Tac Toe Game**: Play against an intelligent AI opponent
- **Racing Game**: Fast-paced 2D racing experience
- **Sudoku Game**: Classic puzzle game with multiple difficulty levels
- **Live News Feed**: Curated news from various categories
- **Daily Facts**: Interesting facts about science, technology, and more

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js server

## Installation

1. Clone the repository
2. Install dependencies: `npm install`
3. Start the server: `node server.js`
4. Visit `http://localhost:8080`
